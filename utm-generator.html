Campaign UTM Generator

This Python-based application automates the creation of UTM URLs for marketing campaigns. It supports multiple channels, platforms, and tactics, generating clean, structured links ready for tracking across digital campaigns.

The tool ensures consistency in naming conventions, reduces manual errors, and streamlines the process of preparing marketing analytics-ready URLs.

The Problem

Marketers often spend significant time manually creating UTM URLs for multiple campaigns, platforms, and tactics.

This process was error-prone and inconsistent, causing issues such as:

  • Inconsistent naming conventions across campaigns
  • Errors in UTM parameters (utm_source, utm_medium, utm_campaign)
  • Difficulty tracking campaign performance accurately
  • Time-consuming manual URL generation for each platform/tactic combination

Overall, manual UTM creation reduced productivity and created unreliable tracking data.

The Solution

The Campaign UTM Generator automates UTM URL creation using a Python + Streamlit web interface.

Key features include:

  • Support for multiple channels (Display, Social, Search, Email)
  • Select specific platforms and tactics per channel
  • Automatic generation of utm_source, utm_medium, utm_campaign, utm_content, and optional utm_term
  • Exportable CSV tracking for all generated URLs
  • Interactive selection using Streamlit session state for dynamic URL generation
  • Consistent naming conventions for campaigns and tactics
  • Audit-friendly tracking to avoid duplicate URLs

The Result

The UTM Generator replaced manual spreadsheet workflows with a dynamic, automated web app.

The solution delivered:

  • Faster URL generation for campaigns across multiple platforms
  • Reduced human errors and inconsistencies
  • Ability to handle multiple tactics and channels at scale
  • Clean CSV outputs ready for marketing analytics tools
  • Improved campaign tracking accuracy and reporting efficiency

The tool enables marketers to quickly generate standardized UTM URLs, improving campaign tracking and ROI measurement.
